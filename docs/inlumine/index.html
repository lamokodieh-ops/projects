InLumine

PRESEC alumni platform (Next.js + Prisma + NextAuth). It needs a real server and database, so GitHub Pages cannot host a full live app.

Fastest way to try it

Clone the monorepo, then in inlumine: 

npm install
npm run db:setup
npm run dev

Demo alumni login is documented in the project README (prefilled on the login page).

Public hosted demo

Deploy to Vercel + Postgres (Neon/Supabase) using the project README. After you have a URL, we can link Open demo from the gallery to that deployment.

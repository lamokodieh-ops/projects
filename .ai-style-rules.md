## [Naming & State-Control Rules]

- Keep each project independent. Do not add a repo-root shared package.
- TypeScript routes: validate with Zod, return `{ error: string }` to the client, log unexpected errors server-side.
- Flask JSON APIs: `jsonify({"error": "..."})` with explicit status codes; parameterized queries only.
- FeedMe stays in `app.py` plus tiny helpers (`security.py`); do not split it into a framework.
- Native CLI apps stay comment-heavy C / C++17 with Makefile entrypoints.
- Gallery demos live under `docs/` and are published from `main`.

## [DONTs]

- Do not concatenate SQL or use `scanf("%s")` without a width.
- Do not hardcode `debug=True` on Flask `app.run`.
- Do not ship production with default `SECRET_KEY` / `JWT_SECRET_KEY` / `FLASK_SECRET_KEY`.
- Do not prefill live login forms with demo passwords.
- Do not swallow API `catch` blocks without a statused response.
- Do not introduce `any` in InLumine TypeScript.
